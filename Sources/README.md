# Reference paper

`hos_of_hrv.pdf` is an unmodified copy of:

Chua, K. C., Chandran, V., Acharya, R. U., and Lim, C. M. (2009). **Cardiac Health Diagnosis Using Higher Order Spectra and Support Vector Machine**. *The Open Medical Informatics Journal*, 3, 1–8. DOI: [10.2174/1874431100903010001](https://doi.org/10.2174/1874431100903010001).

- [PubMed Central article](https://pmc.ncbi.nlm.nih.gov/articles/PMC2709931/)

The paper is included for academic reference and implementation review. Its original ECG recordings are not included.

The local `HOSA(1).PDF` is a separate MATLAB toolbox guide. It is not part of the published repository; the relevant software is linked in the methods audit.
